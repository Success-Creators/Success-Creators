# Success-Creators
Step 1: Create a GitHub Account

1. Visit [github.com](https://github.com/).
2. Click on Sign up.
3. Enter your email, choose a username, and set a password.
4. Verify your email address.

Step 2: Create a New Repository

1. Once logged in, click the + icon in the top-right corner and select New Repository.
2. Name your repository as `username.github.io`, replacing `username` with your GitHub username.
3. Set the repository to Public.
4. Click Create repository.

Step 3: Add Your Website Files

1. Navigate to your new repository.
2. Click on Add file > Create new file.
3. Name the file `index.html`.
4. Add your HTML code.
5. Scroll down and click Commit new file.
6. Repeat steps 2–5 to add other files like `style.css` or `script.js` if needed.

Step 4: Enable GitHub Pages

1. Go to your repository's Settings.
2. Scroll down to the Pages section.
3. Under Source, select the `main` branch and `/ (root)` folder.
4. Click Save.

Step 5: Access Your Live Website

Your website will be live at `https://username.github.io` within a few minutes.
